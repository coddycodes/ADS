# Profiler Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an opt-in, per-environment Profiler. Off by default, it records
crashes, subprocess deaths, memory leaks, CPU, worktree-removal problems and
slow requests on both server and client. It stores them as local NDJSON and
exposes them to AI harnesses through a CLI, a stdio MCP server and a repository
skill.

**Architecture:** A new `apps/server/src/diagnostics/profiler/` module owns a
process-global `ProfilerHandle`: a bounded `std::sync::mpsc` channel feeding one
writer thread. Detectors (sampler, leak, latency, worktree audit, exit watch)
emit events and findings through the handle. A `ProfilerRuntime` starts and
stops detectors when `enableProfiler` changes. The crash handler is attached
once in each `main()`; the monitor child (the same binary relaunched with
`--crash-monitor`) follows the toggle. Clients send compact batches over one new
RPC, and a read-only reader serves the UI RPC, the CLI and the MCP server.

**Tech Stack:** Rust (Tokio/Axum, `sysinfo` 0.39.6, `crash-handler` ≥ 0.8.1,
`minidumper` 0.11, `minidump-processor`), Tauri 2, React + Effect atoms,
`effect/Schema` contracts, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-09-profiler-design.md`. The research
behind it is `docs/plans/2026-10-09-profiler-research.md`. Read both before
starting any task.

## Global Constraints

- Default `enableProfiler: false`. The toggle persists across restarts and
  applies live, with no restart.
- Overhead ≤ 1% CPU on average. Sampling every 5 s, process rediscovery every
  60 s, worktree scan every 10 min.
- Retention: 7 days or 256 MB per data root, including dumps. At most 20 dumps.
- Hot paths never block. They `try_send` into a channel of 2048 events; a full
  channel drops the event and increments a counter.
- Files rotate at 10 MiB, with a 64 KiB `BufWriter` flushed every 2 s and
  `sync_data` only on rotation and shutdown.
- Never record prompt, message or terminal content. Redact in the collector.
  Minidumps never leave the machine unless explicitly asked.
- `crash-handler = ">=0.8.1, <0.9"`, `minidumper = "0.11"`. The handler is
  attached once and **never detached**. The panic hook **never aborts**.
- Slow-request rule: relative tier `max(3 × p95, floor)` after 100 samples, with
  a floor of 250 ms interactive and 1 s background, **log-only in this PR**.
  Absolute tiers at 1 s (warn) and 10 s (severe) raise findings.
- Leak rule: 1-minute medians, 15-minute warm-up, rolling 10-minute minimum.
  Theil–Sen slope ≥ max(10 MB/h, 2%/h) over 1 h plus Mann–Kendall Z > 2.33 →
  suspect. 6 h with R² > 0.8, or ≥ 50% and ≥ 200 MB → likely. Two consecutive
  hits; at most one finding per 6 h per process.
- Privileged desktop operations cross `DesktopBridge`; app traffic uses typed
  RPC. No production Node runtime. Same-binary `--crash-monitor` is the only
  sidecar exception.
- Windows arm64: native dumps disabled until a runtime test passes.
- Every commit follows the repo rule: `codex review -c sandbox_mode="read-only" --uncommitted`,
  then triage with `superpowers:receiving-code-review`, then commit.
- Cargo on the dev host: `systemd-run --user --scope -q -p MemoryMax=20G -p MemorySwapMax=0 env CARGO_BUILD_JOBS=4 cargo …`;
  `vp` is invoked as `node scripts/run-local-vp.mjs …`.

## Review Focus

1. **Profiler directory unwritable or disk full.** The writer thread must keep
   running, count the failed writes as drops, set `capabilities.storage = "failing"`,
   and never panic or block a caller. Test in Task 2.
2. **Toggle flipped rapidly on and off.** There must never be two samplers or
   two monitor children. The final state must match the last setting. Test in
   Task 4 and Task 13.
3. **System sleep or clock jumps during sampling.** A gap of more than 5 minutes
   between samples resets the leak window, and the gap is not read as growth.
   Latency samples that span a sleep are discarded. Tests in Task 7 and Task 10.
4. **An oversized or malicious client batch.** Over 64 records, 64 histograms or
   a 64 KiB payload is rejected with a typed error, nothing is written, and the
   connection stays open. Test in Task 10.
5. **The first start after a crash with the toggle off.** The sentinel must
   still classify the previous run, and the finding must appear when the user
   turns the profiler on. Test in Task 5.

```ts
import * as Schema from "effect/Schema";

export const PROFILER_CLIENT_BATCH_LIMITS = { records: 64, histograms: 64 } as const;

export const ProfilerSeverity = Schema.Literals(["info", "warn", "error"]);
export const ProfilerFindingState = Schema.Literals(["open", "resolved"]);

export const ProfilerFinding = Schema.Struct({
  id: Schema.String,
  fingerprint: Schema.String,
  kind: Schema.String,
  severity: ProfilerSeverity,
  firstSeen: Schema.String,
  lastSeen: Schema.String,
  count: Schema.Number,
  source: Schema.String,
  title: Schema.String,
  summary: Schema.String,
  state: ProfilerFindingState,
});
export type ProfilerFinding = typeof ProfilerFinding.Type;

const CapabilityState = Schema.Literals(["available", "unavailable", "disabled"]);

export const ProfilerStatus = Schema.Struct({
  enabled: Schema.Boolean,
  recordingSince: Schema.NullOr(Schema.String),
  diskBytes: Schema.Number,
  eventCount: Schema.Number,
  droppedEvents: Schema.Number,
  lastCrashAt: Schema.NullOr(Schema.String),
  capabilities: Schema.Struct({
    nativeDumps: CapabilityState,
    osCrashRecords: CapabilityState,
    storage: Schema.Literals(["ok", "failing"]),
  }),
  findings: Schema.Array(ProfilerFinding),
});
export type ProfilerStatus = typeof ProfilerStatus.Type;

export const ProfilerClientRecord = Schema.Struct({
  correlationId: Schema.NullOr(Schema.String),
  method: Schema.String,
  rttMs: Schema.Number,
  renderMs: Schema.NullOr(Schema.Number),
  startedAtMs: Schema.Number,
});

/** Log-bucket counts per method, bucket i covers (1.12^i, 1.12^(i+1)] ms. */
export const ProfilerClientHistogram = Schema.Struct({
  method: Schema.String,
  buckets: Schema.Array(Schema.Tuple([Schema.Number, Schema.Number])),
});

export const ProfilerClientBatch = Schema.Struct({
  clientId: Schema.String,
  capabilities: Schema.Array(Schema.String),
  windowMs: Schema.Number,
  records: Schema.Array(ProfilerClientRecord).check(
    Schema.isMaxLength(PROFILER_CLIENT_BATCH_LIMITS.records),
  ),
  histograms: Schema.Array(ProfilerClientHistogram).check(
    Schema.isMaxLength(PROFILER_CLIENT_BATCH_LIMITS.histograms),
  ),
  stalls: Schema.Struct({ count: Schema.Number, totalMs: Schema.Number, maxMs: Schema.Number }),
  interactions: Schema.Struct({ count: Schema.Number, maxMs: Schema.Number }),
  jsHeapBytes: Schema.NullOr(Schema.Number),
});
export type ProfilerClientBatch = typeof ProfilerClientBatch.Type;

export const ProfilerClientBatchResult = Schema.Struct({ accepted: Schema.Boolean });
export type ProfilerClientBatchResult = typeof ProfilerClientBatchResult.Type;
```

```rust
// bottom of store.rs
#[cfg(test)]
mod tests {
    use super::*;
    use serde_json::json;

    fn config(dir: &std::path::Path) -> StoreConfig {
        StoreConfig {
            max_file_bytes: 300,
            flush_every: std::time::Duration::from_millis(10),
            ..StoreConfig::new(dir.to_path_buf())
        }
    }

    fn event(n: u64) -> ProfilerEvent {
        ProfilerEvent { kind: "test.event", source: "server".into(), payload: json!({ "n": n }) }
    }

    #[test]
    fn writes_ndjson_envelopes_and_rotates_by_size() {
        let dir = tempfile::tempdir().unwrap();
        let store = ProfilerStore::start(config(dir.path()));
        for n in 0..20 {
            store.sender().send(event(n));
        }
        store.shutdown();
        let mut files: Vec<_> = std::fs::read_dir(dir.path())
            .unwrap()
            .map(|e| e.unwrap().file_name().into_string().unwrap())
            .filter(|n| n.starts_with("events-"))
            .collect();
        files.sort();
        assert!(files.len() > 1, "300-byte cap must rotate: {files:?}");
        let first = std::fs::read_to_string(dir.path().join(&files[0])).unwrap();
        let line: serde_json::Value = serde_json::from_str(first.lines().next().unwrap()).unwrap();
        assert_eq!(line["v"], 1);
        assert_eq!(line["kind"], "test.event");
        assert_eq!(line["seq"], 0);
        assert_eq!(line["sid"].as_str().unwrap().len(), 8, "every writer start has a session id");
        assert!(line["ts"].as_str().unwrap().ends_with('Z'));
    }

    #[test]
    fn full_channel_drops_and_reports_a_dropped_event() {
        let dir = tempfile::tempdir().unwrap();
        let store = ProfilerStore::start_paused(config(dir.path()), 4);
        for n in 0..10 {
            store.sender().send(event(n));
        }
        assert_eq!(store.stats().dropped, 6);
        store.resume();
        store.shutdown();
        let all = read_all(dir.path());
        assert!(all.iter().any(|l| l["kind"] == "telemetry.dropped" && l["count"] == 6));
    }

    #[test]
    fn unwritable_directory_marks_failing_without_panicking() {
        let dir = tempfile::tempdir().unwrap();
        let blocker = dir.path().join("profiler");
        std::fs::write(&blocker, b"not a dir").unwrap();
        let store = ProfilerStore::start(config(&blocker));
        store.sender().send(event(1));
        std::thread::sleep(std::time::Duration::from_millis(50));
        assert!(store.stats().failing);
        store.shutdown();
    }

    #[test]
    fn retention_deletes_crash_dumps_when_events_alone_cannot_fit() {
        let dir = tempfile::tempdir().unwrap();
        let crashes = dir.path().join("crashes");
        std::fs::create_dir_all(&crashes).unwrap();
        std::fs::write(crashes.join("old.dmp"), vec![0u8; 800]).unwrap();
        std::fs::write(crashes.join("old.json"), b"{}").unwrap();
        let store = ProfilerStore::start(StoreConfig { max_total_bytes: 900, ..config(dir.path()) });
        for n in 0..40 {
            store.sender().send(event(n));
        }
        store.shutdown();
        assert!(!crashes.join("old.dmp").exists());
        assert!(!crashes.join("old.json").exists());
    }

    #[test]
    fn retention_deletes_oldest_files_over_total_cap() {
        let dir = tempfile::tempdir().unwrap();
        let store = ProfilerStore::start(StoreConfig { max_total_bytes: 900, ..config(dir.path()) });
        for n in 0..200 {
            store.sender().send(event(n));
        }
        store.shutdown();
        let total: u64 = std::fs::read_dir(dir.path())
            .unwrap()
            .map(|e| e.unwrap().metadata().unwrap().len())
            .sum();
```

```rust
enum Message {

#[derive(Clone)]
pub struct EventSender {
    tx: SyncSender<Message>,
    counters: Arc<Counters>,
}

impl EventSender {
    /// Never blocks; a full channel drops the event and counts it.
    pub fn send(&self, event: ProfilerEvent) {
        match self.tx.try_send(Message::Event(event)) {
            Ok(()) => {}
            Err(TrySendError::Full(_) | TrySendError::Disconnected(_)) => {
                self.counters.dropped.fetch_add(1, Ordering::Relaxed);
            }
        }
    }

pub struct ProfilerStore {
    sender: EventSender,
    thread: Option<JoinHandle<()>>,
    pause: Option<SyncSender<()>>,
}

impl ProfilerStore {
    pub fn start(config: StoreConfig) -> Self {
        Self::spawn(config, CHANNEL_CAPACITY, false)
    }

    #[cfg(test)]
    fn start_paused(config: StoreConfig, capacity: usize) -> Self {
        Self::spawn(config, capacity, true)
    }

    #[cfg(test)]
    fn resume(&self) {
        if let Some(pause) = &self.pause {
            let _ = pause.send(());
        }
    }

    fn spawn(config: StoreConfig, capacity: usize, paused: bool) -> Self {
        let (tx, rx) = mpsc::sync_channel(capacity);
        let counters = Arc::new(Counters::default());
        let (pause_tx, pause_rx) = mpsc::sync_channel::<()>(1);
        let writer_counters = counters.clone();
        let thread = std::thread::Builder::new()
            .name("bibcode-profiler-writer".into())
            .spawn(move || {
                if paused {
                    let _ = pause_rx.recv();
                }
                Writer::new(config, writer_counters).run(rx);
            })
            .expect("spawn profiler writer thread");
        Self {
            sender: EventSender { tx, counters },
            thread: Some(thread),
            pause: paused.then_some(pause_tx),
        }
    }

    pub fn sender(&self) -> EventSender {
        self.sender.clone()
    }

    pub fn stats(&self) -> StoreStats {
        let c = &self.sender.counters;
        StoreStats {
            written: c.written.load(Ordering::Relaxed),
            dropped: c.dropped.load(Ordering::Relaxed),
            failing: c.failing.load(Ordering::Relaxed),
        }
    }

    pub fn shutdown(mut self) {
        self.resume_if_paused();
        // Shutdown is queued behind pending events, so they are all written first.
        let _ = self.sender.tx.send(Message::Shutdown);
        if let Some(thread) = self.thread.take() {
            let _ = thread.join();
        }
    }

    fn resume_if_paused(&self) {
        if let Some(pause) = &self.pause {
            let _ = pause.try_send(());
        }
    }
}

struct Writer {
    config: StoreConfig,
    counters: Arc<Counters>,
    out: Option<(BufWriter<File>, u64)>,
    next_file: u64,
    seq: u64,
    sid: String,
    reported_drops: u64,
}

impl Writer {
    fn new(config: StoreConfig, counters: Arc<Counters>) -> Self {
        let next_file = existing_max_file_index(&config.dir).map_or(0, |n| n + 1);
        // `sid` makes event references unique across restarts: `seq` restarts at 0
        // for each writer session, so evidence is always `"<sid>:<seq>"`.
        let sid = uuid::Uuid::new_v4().simple().to_string()[..8].to_owned();
        Self { config, counters, out: None, next_file, seq: 0, sid, reported_drops: 0 }
    }

    fn run(mut self, rx: Receiver<Message>) {
        let mut last_flush = Instant::now();
        loop {
            match rx.recv_timeout(self.config.flush_every) {
                Ok(Message::Event(event)) => self.write(event),
                Ok(Message::Finding(finding)) => self.append_finding(&finding),
                Ok(Message::Shutdown) | Err(RecvTimeoutError::Disconnected) => break,
                Err(RecvTimeoutError::Timeout) => {}
            }
            if last_flush.elapsed() >= self.config.flush_every {
                self.report_drops();
                self.flush();
                last_flush = Instant::now();
            }
        }
        self.report_drops();
        if let Some((mut out, _)) = self.out.take() {
            let _ = out.flush();
            let _ = out.get_ref().sync_data();
        }
    }

    fn report_drops(&mut self) {
        let dropped = self.counters.dropped.load(Ordering::Relaxed);
        if dropped > self.reported_drops {
            let count = dropped - self.reported_drops;
            self.reported_drops = dropped;
            self.write_value(json!({ "kind": "telemetry.dropped", "source": "server", "count": count }));
        }
    }

    fn write(&mut self, event: ProfilerEvent) {
        let mut line = json!({ "kind": event.kind, "source": event.source });
        if let (Value::Object(target), Value::Object(payload)) = (&mut line, event.payload) {
            target.extend(payload);
        }
        self.write_value(line);
    }

    fn write_value(&mut self, mut line: Value) {
        line["v"] = json!(1);
        line["seq"] = json!(self.seq);
        line["sid"] = json!(self.sid);
        line["ts"] = json!(now_rfc3339());
        self.seq += 1;
        let mut bytes = match serde_json::to_vec(&line) {
            Ok(bytes) => bytes,
            Err(_) => return,
        };
        bytes.push(b'\n');
        if let Err(()) = self.append(&bytes) {
            self.counters.failing.store(true, Ordering::Relaxed);
            self.counters.dropped.fetch_add(1, Ordering::Relaxed);
            // The failed write is counted as a drop, so don't report it again.
            self.reported_drops += 1;
            self.out = None;
            return;
        }
        self.counters.failing.store(false, Ordering::Relaxed);
        self.counters.written.fetch_add(1, Ordering::Relaxed);
    }

    fn append(&mut self, bytes: &[u8]) -> Result<(), ()> {
        let needs_rotation = self
            .out
            .as_ref()
            .is_some_and(|(_, len)| len + bytes.len() as u64 > self.config.max_file_bytes);
        if needs_rotation {
            if let Some((mut out, _)) = self.out.take() {
                let _ = out.flush();
                let _ = out.get_ref().sync_data();
            }
            self.enforce_retention();
        }
        if self.out.is_none() {
            fs::create_dir_all(&self.config.dir).map_err(|_| ())?;
            let path = self.config.dir.join(format!("events-{:06}.ndjson", self.next_file));
            self.next_file += 1;
            let file = OpenOptions::new().create(true).append(true).open(path).map_err(|_| ())?;
            self.out = Some((BufWriter::with_capacity(64 * 1024, file), 0));
        }
        let (out, len) = self.out.as_mut().expect("opened above");
        out.write_all(bytes).map_err(|_| ())?;
        *len += bytes.len() as u64;
        Ok(())
    }

    fn flush(&mut self) {
        if let Some((out, _)) = self.out.as_mut()
            && out.flush().is_err()
        {
            self.counters.failing.store(true, Ordering::Relaxed);
        }
    }

    /// Retention for the whole profiler directory, run on every rotation and once at start:
    /// 1. rotated `events-*` files older than `max_age` are deleted;
    /// 2. while the total (events + `crashes/` + `findings.ndjson`) exceeds `max_total_bytes`,
    ///    delete the oldest rotated events file;
    /// 3. if only the live events file is left and it is still over budget, delete the oldest
    ///    crash dump and its `.json` sidecar, repeating until under budget.
    /// `findings.ndjson` is bounded separately by compaction (Task 3).
    fn enforce_retention(&self) {
        let mut files = event_files(&self.config.dir);
        let now = SystemTime::now();
        let mut total: u64 = files.iter().map(|f| f.1).sum::<u64>() + dir_size(&self.config.dir.join("crashes"));
        files.sort_by_key(|f| f.2);
        for (path, len, modified) in files {
            let expired = now.duration_since(modified).is_ok_and(|age| age > self.config.max_age);
            if expired || total > self.config.max_total_bytes {
                if fs::remove_file(&path).is_ok() {
                    total = total.saturating_sub(len);
                }
            }
        }
        total += file_len(&self.config.dir.join("findings.ndjson"));
        for (dump, len) in crash_dumps_oldest_first(&self.config.dir.join("crashes")) {
            if total <= self.config.max_total_bytes {
                break;
            }
            let _ = fs::remove_file(dump.with_extension("json"));
            if fs::remove_file(&dump).is_ok() {
                total = total.saturating_sub(len);
            }
        }
    }
}
```

```rust
pub fn redact_command(command: &str) -> String {
    let first = command.split_whitespace().next().unwrap_or("");
    let name = std::path::Path::new(first)
        .file_name()
        .map(|n| n.to_string_lossy().into_owned())

}

/// Secret redaction, control-character stripping, and a 2 KiB cap.
pub fn redact_message(value: &str) -> String {
    let cleaned: String = redact_sensitive_text(value)
        .chars()
        .filter(|c| !c.is_control() || *c == '\n' || *c == '\t')
        .collect();
    let mut end = cleaned.len().min(2048);
    while !cleaned.is_char_boundary(end) {
        end -= 1;
    }
    cleaned[..end].to_owned()
}
```

```rust
pub fn install_panic_hook() {
    static ONCE: std::sync::Once = std::sync::Once::new();
    ONCE.call_once(|| {
        let previous = std::panic::take_hook();
        std::panic::set_hook(Box::new(move |info| {
            let mut frames = Vec::with_capacity(64);
            backtrace::trace(|frame| {
                frames.push(frame.ip() as usize);
                frames.len() < 64
            });
            let mapped: Vec<_> = frames.into_iter().filter_map(module_offset).collect();
            let message = super::redact::redact_path(&panic_message(info));
            let thread = std::thread::current().name().unwrap_or("unnamed").to_owned();
            let location = info.location().map(|l| format!("{}:{}", l.file(), l.line()));
            // Panics are recorded even with the profiler off: route through the sender directly.
            if let Some(handle) = super::global() {
                handle.sender.send(super::event::ProfilerEvent {
                    kind: "panic",
                    source: "server".into(),
                    payload: serde_json::json!({ "thread": thread, "message": message,
                        "location": location, "frames": mapped }),
                });
            }
            previous(info);
        }));
    });
}
```

`module_offset(ip)` returns `{ module, debugId, offset }`:

- **Unix:** `libc::dladdr` gives `dli_fname` and `dli_fbase`;
  `offset = ip - dli_fbase`. The debug ID comes from a startup cache built from
  our own executable: the ELF `.note.gnu.build-id` read by parsing
  `std::env::current_exe()`, or the Mach-O `LC_UUID`.
- **Windows:** `backtrace::Frame::module_base_address()`, with the PDB GUID+age
  from the PE debug directory.

Keep the cache tiny, holding only the main executable. Frames in other modules
get `debugId: null`.

The location's file path is compile-time (`src/...`), so it is safe as is.

```rust
const WARMUP_MIN: u64 = 15;
const FLOOR_WINDOW_MIN: usize = 10;
const SUSPECT_WINDOW_MIN: usize = 60;
const LIKELY_WINDOW_MIN: usize = 360;
const GAP_RESET_MIN: u64 = 5;
const MB: f64 = 1024.0 * 1024.0;
const STEP_MIN_BYTES: f64 = 64.0 * MB;

#[derive(Default)]
pub struct LeakDetector {
    raw: std::collections::VecDeque<(u64, f64)>,    // (minute, bytes) since last reset
    floor: std::collections::VecDeque<(u64, f64)>,  // rolling-minimum series
    started: Option<u64>,
    last_minute: Option<u64>,
    baseline: Option<f64>,
    consecutive_hits: u8,
    last_alert: Option<u64>,
}

impl LeakDetector {
    pub fn window_len(&self) -> usize { self.raw.len() }

    pub fn push_minute(&mut self, minute: u64, private_bytes: u64) -> Option<LeakVerdict> {
        let value = private_bytes as f64;
        if self.last_minute.is_some_and(|last| minute.saturating_sub(last) > GAP_RESET_MIN) {
            self.reset(minute);
        }
        self.last_minute = Some(minute);
        let started = *self.started.get_or_insert(minute);
        self.raw.push_back((minute, value));
        while self.raw.len() > LIKELY_WINDOW_MIN { self.raw.pop_front(); }
        let floor_value = self.raw.iter().rev().take(FLOOR_WINDOW_MIN).map(|p| p.1).fold(f64::INFINITY, f64::min);
        if minute - started < WARMUP_MIN { return None; }
        // A step change > 3σ of the recent floor resets the baseline (RESIN).
        if let Some(prev) = self.floor.back().map(|p| p.1) {
            let sigma = std_dev(self.floor.iter().rev().take(SUSPECT_WINDOW_MIN).map(|p| p.1));
            // A flat floor has sigma 0, so the minimum jump must not depend on sigma alone.
            // 64 MB per minute only resets for genuine steps; a 30 MB/h leak moves the
            // floor ~0.5 MB per minute and is never mistaken for a step.
            if self.floor.len() >= FLOOR_WINDOW_MIN && (floor_value - prev).abs() > (3.0 * sigma).max(STEP_MIN_BYTES) {
                self.reset_keep(minute, floor_value);
                return None;
            }
        }
        self.floor.push_back((minute, floor_value));
        while self.floor.len() > LIKELY_WINDOW_MIN { self.floor.pop_front(); }
        let baseline = *self.baseline.get_or_insert(floor_value);
        let verdict = self.evaluate(baseline);
        match verdict {
            LeakVerdict::None => { self.consecutive_hits = 0; None }
            hit => {
                self.consecutive_hits = self.consecutive_hits.saturating_add(1);
                let cooled = self.last_alert.is_none_or(|t| minute - t >= 360);
                if self.consecutive_hits >= 2 && cooled {
                    self.last_alert = Some(minute);
                    Some(hit)
                } else { None }
            }
        }
    }

    fn evaluate(&self, baseline: f64) -> LeakVerdict {
        if self.floor.len() < SUSPECT_WINDOW_MIN { return LeakVerdict::None; }
        let points: Vec<(f64, f64)> = self.floor.iter().map(|(m, v)| (*m as f64 / 60.0, *v / MB)).collect();
        let recent = &points[points.len() - SUSPECT_WINDOW_MIN..];
        let slope = theil_sen(recent); // MB per hour
        let threshold = (10.0f64).max(0.02 * baseline / MB);
        let z = mann_kendall_z(&recent.iter().map(|p| p.1).collect::<Vec<_>>());
        let latest = points.last().map_or(0.0, |p| p.1);
        let growth = latest - baseline / MB;
        if points.len() >= LIKELY_WINDOW_MIN {
            let r2 = r_squared(&points);
            if (slope >= 5.0 && r2 > 0.8) || (growth >= 200.0 && growth >= 0.5 * baseline / MB) {
                return LeakVerdict::Likely { slope_mb_per_h: slope, r2 };
            }
        }
        if slope >= threshold && z > 2.33 { LeakVerdict::Suspect { slope_mb_per_h: slope } } else { LeakVerdict::None }
    }

    fn reset(&mut self, minute: u64) {
        self.raw.clear();
        self.floor.clear();
        self.started = Some(minute);
        self.baseline = None;
        self.consecutive_hits = 0;
    }

    fn reset_keep(&mut self, minute: u64, floor_value: f64) {
        self.floor.clear();
        self.floor.push_back((minute, floor_value));
        self.baseline = Some(floor_value);
        self.consecutive_hits = 0;
    }
}

pub fn theil_sen(points: &[(f64, f64)]) -> f64 {
    let mut slopes = Vec::with_capacity(points.len() * points.len() / 2);
    for i in 0..points.len() {
        for j in i + 1..points.len() {
            let dx = points[j].0 - points[i].0;
            if dx != 0.0 { slopes.push((points[j].1 - points[i].1) / dx); }
        }
    }
    median(&mut slopes)
}

pub fn mann_kendall_z(values: &[f64]) -> f64 {
    let n = values.len() as f64;
    if n < 3.0 { return 0.0; }
    let mut s = 0.0;
    for i in 0..values.len() {
        for j in i + 1..values.len() {
            let d = values[j] - values[i];
            s += if d > 0.0 { 1.0 } else if d < 0.0 { -1.0 } else { 0.0 };
        }
    }
    let var = n * (n - 1.0) * (2.0 * n + 5.0) / 18.0;
    if s > 0.0 { (s - 1.0) / var.sqrt() } else if s < 0.0 { (s + 1.0) / var.sqrt() } else { 0.0 }
}

pub fn r_squared(points: &[(f64, f64)]) -> f64 {
    let n = points.len() as f64;
    let (mx, my) = (points.iter().map(|p| p.0).sum::<f64>() / n, points.iter().map(|p| p.1).sum::<f64>() / n);
    let (mut sxy, mut sxx, mut syy) = (0.0, 0.0, 0.0);
    for (x, y) in points { sxy += (x - mx) * (y - my); sxx += (x - mx).powi(2); syy += (y - my).powi(2); }
    if sxx == 0.0 || syy == 0.0 { return 0.0; }
    (sxy * sxy) / (sxx * syy)
}
```
